# SSL-Vision

**注意:** このドキュメントは外部ソフトウェアである `RoboCup-SSL/ssl-vision` のセットアップと設定に関する一般的なガイダンスを提供します。具体的なUIの項目名や設定手順は、プロジェクトで使用している `ssl-vision` のバージョンによって異なる場合があります。常に使用しているバージョンに対応する情報を確認してください。

`ssl-vision` は、RoboCup SSL環境においてフィールド上のロボットやボールの位置情報を取得するために不可欠な外部コンポーネントです。このシステムは、カメラからの映像を処理し、試合のリアルタイムな状態をネットワーク経由で提供します。

craneプロジェクトでは、この`ssl-vision`からの情報が、ロボットの認識やワールドモデルの構築の基礎となります。

**インストール、設定、および操作の詳細については、以下の公式ドキュメントを参照してください。**

-   **Official `RoboCup-SSL/ssl-vision` Repository:** [https://github.com/RoboCup-SSL/ssl-vision](https://github.com/RoboCup-SSL/ssl-vision)

プロジェクトで使用する`ssl-vision`のバージョンに合わせた公式の指示に従ってセットアップを行ってください。
